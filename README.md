# Memory Flip Card Game - Monorepo

This repository contains:
- backend/ (FastAPI) — API for the Memory Flip Card game
- memory_flip_card_frontend/ (React) — UI to play the game

Getting Started:
- See backend/README.md for API run instructions and endpoints.
- See the frontend README in its folder for UI instructions.

APIs:
- Swagger UI (when backend is running): http://localhost:3001/docs
- OpenAPI spec: http://localhost:3001/openapi.json
